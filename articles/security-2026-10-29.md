Linux の脆弱性（CVE-2026-98432）がニュースになっています。Ubuntu だけでなく、Amazon Linux など Linux を使う多くの環境に関わるものです。

コマドリとこのサイトは、自分で管理するサーバーを持たず、AWS が管理する仕組み（AWS Lambda と Amazon S3）の上で動いています。その土台の更新は AWS が行います。外から直接つながる口も開けていないため、影響はないと考えています。PHP も使っていません。

アプリは登録なしで使え、お名前やメールアドレスはお預かりしていません（お問い合わせでいただいたメールアドレスは、お返事にだけ使います）。何を送って、何が残るかは、[コマドリのプライバシーポリシー](/komadori/privacy.html)に書いています。

セキュリティの更新が出たときは、速やかに対応します。
